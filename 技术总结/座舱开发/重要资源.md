#### 一、概念
##### 1)车机服务部件
> - Icm     IcmManagerWrapper-Instrument Cluster Module 组合仪表
> - Mcu    McuManagerWrapper-Microcontroller Unit 微控制单元
> - Bcm    BcmManagerWrapper-Body Control Module 车身控制器
> - TBox   TBoxManagerWrapper-Telematics Box 车载远程通信装置
> - Avm    AvmManagerWrapper-Around View Monitor 全景影像监测
> - CIU     CiuManagerWrapper-Cabin Intelligent Unit 车内智能模块
> - Srs      SrsManagerWrapper-Supplemental Restraint System 安全气囊控制器
> - Vcu     VcuManagerWrapper-Vehicle Control Unit 整车控制器
> - Xpu    XpuManagerWrapper-Xiaopeng Processing Unit 小鹏汽车的自动驾驶控制器
