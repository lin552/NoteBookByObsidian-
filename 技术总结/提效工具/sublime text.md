#### 一、快捷键

| 功能        | Windows 快捷键        | macOS 快捷键          |
| --------- | ------------------ | ------------------ |
| 打开命令面板    | `Ctrl+Shift+P`     | `Cmd+Shift+P`      |
| 快速打开文件    | `Ctrl+P`           | `Cmd+P`            |
| 跳转到行      | `Ctrl+G`           | `Cmd+G`            |
| 多光标选择（单词） | `Ctrl+D`           | `Cmd+D`            |
| 多光标选择（行）  | `Ctrl+L`           | `Cmd+L`            |
| 注释/取消注释   | `Ctrl+/`           | `Cmd+/`            |
| 复制整行      | `Ctrl+Shift+D`     | `Cmd+Shift+D`      |
| 删除整行      | `Ctrl+Shift+K`     | `Cmd+Shift+K`      |
| 折叠/展开代码块  | `Ctrl+Shift+[`/`]` | `Cmd+Option+[`/`]` |
| 打开命令面板    | `Ctrl+Shift+P`     | `Cmd+Shift+P`      |
| 列选择       | `Shift+Alt`        | `Shift+Option`     |
