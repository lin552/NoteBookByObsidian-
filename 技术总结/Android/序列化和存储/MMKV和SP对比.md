| **对比维度**​     | ​**MMKV**​                                                                | ​**SharedPreferences（SP）​**​                              | ​**适用场景**​                                     |
| ------------- | ------------------------------------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------- |
| ​**性能**​      | 写入性能是 SP 的 ​**10 倍以上**​（实测 1000 次写入耗时 7ms vs SP 的 187ms）                  | 写入需全量序列化 XML，频繁操作易引发 ANR（如 `commit()`阻塞主线程）               | MMKV：高频读写（如用户配置、实时状态）  <br>SP：极少量简单数据（如开关配置）   |
| ​**数据可靠性**​   | - 增量更新（仅修改部分数据）  <br>- CRC 校验 + 自动恢复机制  <br>- 内核级持久化保障                    | - 全量 XML 重写  <br>- 无校验机制，文件损坏难恢复  <br>- `apply()`异步可能丢失数据 | MMKV：需高可靠性的敏感数据（如用户凭证）  <br>SP：临时缓存或可容忍丢失的数据   |
| ​**多进程支持**​   | 原生支持多进程并发读写，通过文件锁保证原子性                                                    | Android 7.0 后多进程模式废弃，自定义实现复杂且性能差                          | MMKV：多进程共享数据（如主进程与推送进程）  <br>SP：单进程场景          |
| ​**数据格式与扩展**​ | - Protobuf 二进制序列化（体积小 30%-50%）  <br>- 支持复杂类型（`byte[]`、`Set`、`Parcelable`） | - XML 文本存储（冗余大）  <br>- 仅支持基础类型（`String`、`int`等）           | MMKV：复杂对象存储（如用户信息 JSON）  <br>SP：简单键值对（如主题模式开关） |
| ​**存储效率**​    | 二进制格式 + 增量更新，存储空间更小                                                       | XML 标签冗余（如 `<string name="key">value</string>`）           | MMKV：大规模数据存储（如缓存元信息）  <br>SP：极小规模配置            |
| ​**跨平台支持**​   | 支持 Android/iOS/macOS/Windows/Linux，API 统一                                 | 仅 Android                                                 | MMKV：多端数据同步（如账号配置）  <br>SP：纯 Android 本地存储      |
| ​**安全机制**​    | 支持 AES-128 加密（密钥存储于 Native 层防反编译）                                         | 需手动实现加密（如 AES），无原生保护                                      | MMKV：敏感数据（如密码、Token）  <br>SP：非敏感数据             |
| ​**迁移与兼容性**​  | 提供 `importFromSharedPreferences()`一键迁移 SP 数据                              | 系统原生方案，无需迁移                                               | SP 迁移至 MMKV 的场景                                |
| ​**内存管理**​    | 内存映射（mmap）零拷贝，进程常驻内存                                                      | 首次加载 XML 到内存，全量缓存                                         | MMKV：高频访问数据（如全局配置）  <br>SP：低频数据                |
