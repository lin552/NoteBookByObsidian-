| ​**维度**​        | ​**静态变量（Static Variable）​**​                                                                | ​**实例变量（Instance Variable）​**​                               |
| --------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| ​**归属**​        | 属于类本身（类级别的变量）。                                                                              | 属于类的实例（对象级别的变量）。                                             |
| ​**内存分配**​      | 类加载时分配到**方法区**​（`JDK8`前）或**元空间**​（`JDK8`后），全局唯一。                                            | 对象创建时分配到**堆内存**，每个实例独立一份。                                    |
| ​**生命周期**​      | 随类的加载而创建，随类的卸载（如JVM退出）而销毁。                                                                  | 随对象的创建（`new`）而创建，随对象的垃圾回收（GC）而销毁。                            |
| ​**访问方式**​      | - 类名直接访问（推荐）：`ClassName.staticVar`  <br>- 实例访问（不推荐）：`object.staticVar`（编译警告）。               | - 必须通过实例访问：`object.instanceVar`  <br>- 不能通过类名访问（编译错误）。       |
| ​**初始化时机**​     | 类加载时初始化（仅一次）：  <br>- 显式初始化（如`static int x = 10;`）  <br>- 隐式初始化（默认值，如`int`默认0，`对象`默认`null`）。 | 对象创建时初始化（每次`new`对象时）：  <br>- 构造方法初始化  <br>- 实例初始化块（`{}`）初始化。 |
| ​**共享性**​       | 所有实例共享同一个静态变量（修改一个实例的静态变量，其他实例可见）。                                                          | 每个实例独立拥有自己的实例变量（修改一个实例的变量，其他实例不受影响）。                         |
| ​**线程安全性**​     | 多线程共享，若被修改需考虑同步（如`static int count`被多线程自增可能引发竞态条件）。                                         | 每个实例独立，多线程操作不同实例时无需同步（操作同一实例时需同步）。                           |
| ​**`this`关键字**​ | 不能使用`this`（`this`指向实例，静态变量无实例依赖）。                                                           | 可以使用`this`（`this.instanceVar`指向当前实例的变量）。                     |
| ​**使用场景**​      | 全局共享数据（如配置信息、计数器、工具类常量）。                                                                    | 对象特有的状态（如`User`对象的`name`、`age`）。                             |
