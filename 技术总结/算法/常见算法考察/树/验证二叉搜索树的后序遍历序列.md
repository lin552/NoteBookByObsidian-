#### 一、题目
**难度**​：中等  
​**考点**​：递归、分治、二叉搜索树性质  
​**题目描述**​：  
输入一个整数数组，判断该数组是否是某二叉搜索树的后序遍历结果。  
​**示例**​：  
输入: `[1,3,2,6,5](@ref)`  
输出: `true`

#### 二、解题思路
1. ​**二叉搜索树性质**​：左子树 < 根节点 < 右子树。
2. ​**分治验证**​：找到第一个大于根节点的位置，验证右侧元素是否全大于根节点，并递归验证左右子树。

#### 三、代码
```java
public boolean verifyPostorder(int[] postorder){
   return verify(postorder,0,postorder.length - 1);
}

private boolean verify(int[] postorder,int left,int right){
   if(left >= right) return true;
   int root = postorder[right];
   int mid = left;
   while(postorder[mid] < root) mid++; //找到第一个大于根的元素
   int i = mid;
   while(i < right){
      if(postorder[i] < root) return false; //右侧存在小于根的元素，非法
      i++;
   }
   return verify(postorder,left,mid - 1) && verify(postorder,mid,right - 1);
}
```
