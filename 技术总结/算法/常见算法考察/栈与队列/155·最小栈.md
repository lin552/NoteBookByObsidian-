#### 一、题目

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素val推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

**示例 1:**

**输入：**
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

**输出：**
[null,null,null,null,-3,null,0,-2]

**解释：**
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.

**提示：**

- `-231 <= val <= 231 - 1`
- `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用
- `push`, `pop`, `top`, and `getMin`最多被调用 `3 * 104` 次

#### 二、解题思路
①使用两个栈，主栈保存所有元素，辅助栈保存当前栈中的最小值。每次操作时，辅助栈同步更新最小值，确保其栈顶始终是当前主栈的最小值。
②使用一个栈，每个栈元素不仅保存值，还保存当前栈中的最小值。通过这种方式，栈顶元素直接记录了当前的最小值。

#### 三、代码
```java
// 1.双栈法
class MinStack {
    private Deque<Integer> mainStack; // 主栈，保存所有元素
    private Deque<Integer> minStack;  // 辅助栈，保存当前最小值

    public MinStack() {
        mainStack = new LinkedList<>();
        minStack = new LinkedList<>();
    }

    public void push(int val) {
        mainStack.push(val);
        // 辅助栈压入当前最小值：若辅助栈为空，当前值为最小值；否则取较小值
        int currentMin = minStack.isEmpty() ? val : Math.min(val, minStack.peek());
        minStack.push(currentMin);
    }

    public void pop() {
        mainStack.pop();
        minStack.pop(); // 辅助栈同步弹出
    }

    public int top() {
        return mainStack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}

//2.单栈法
class MinStack {
    // 内部类：保存值和当前最小值
    private static class Node {
        int val;
        int min;
        Node(int val, int min) {
            this.val = val;
            this.min = min;
        }
    }

    private Deque<Node> stack;

    public MinStack() {
        stack = new LinkedList<>();
    }

    public void push(int val) {
        int currentMin = stack.isEmpty() ? val : Math.min(val, stack.peek().min);
        stack.push(new Node(val, currentMin));
    }

    public void pop() {
        stack.pop();
    }

    public int top() {
        return stack.peek().val;
    }

    public int getMin() {
        return stack.peek().min;
    }
}
```
