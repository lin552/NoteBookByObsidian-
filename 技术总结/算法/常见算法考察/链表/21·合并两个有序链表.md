#### 一、题目
将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。 

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/03/merge_ex1.jpg)

**输入：**l1 = [1,2,4], l2 = [1,3,4]
**输出：**[1,1,2,3,4,4]

**示例 2：**

**输入：**l1 = [], l2 = []
**输出：**[]

**示例 3：**

**输入：**l1 = [], l2 = [0]
**输出：**[0]

**提示：**

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 **非递减顺序** 排列
#### 二、解题思路
1.递归法：因为返回相同，可以使用递归来实现，先边界控制，然后对比`list1.val` 和 `list2.val` 找小的继续递归操作
2.迭代法：使用一个`prehead`指针，遍历`list1` 和 `list2`，将小的添加到`prehead`指针后,并且不断移动next
#### 三、代码
```java
 //1.递归解法
class Solution {

    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        //边界处理
        if(list1 == null){
            return list2;
        } else if(list2 == null){
            return list1;
        } else if(list1.val < list2.val){
            //如果当前值 list1 < list2
            //递归比较list1.next
            list1.next = mergeTwoLists(list1.next,list2);
            return list1;
        } else {
            //如果当前值 list1 > list2
            //递归比较list2.next
            list2.next = mergeTwoLists(list1,list2.next);
            return list2;
        }
    }
}

//2.迭代解法
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        //定义一个哨兵节点
        ListNode prehead = new ListNode(-1);
        //临时指针需要有prev指向结尾
        ListNode prev = prehead;
        //遍历list1 和 list2
        while(list1 != null && list2 != null){
            if(list1.val <= list2.val){
                prev.next = list1;
                list1 = list1.next;
            } else {
                prev.next = list2;
                list2 = list2.next;
            }
            //prev后移，指向下一个
            prev = prev.next;
        }
        //合并后 l1 和 l2 最多只有一个未被合并完，直接将链表末尾指向未合并完的链表即可
        prev.next = list1 == null ? list2 : list1;
        return prehead.next;
    }
}
```
