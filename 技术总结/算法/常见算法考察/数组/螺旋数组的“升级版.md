#### **一、非正方形螺旋数组（m×n矩形）​**​

​**问题描述**​：生成一个 `m` 行 `n` 列的螺旋数组，数字从1开始按顺时针方向填充，直到填满所有位置。  
​**核心差异**​：基础螺旋是正方形（n×n），升级为矩形（m×n）后，螺旋的层数由较小的边决定（如3×5的螺旋层数为3层）。

##### ​**算法思路**​
1. ​**初始化矩阵**​：创建 `m×n` 的二维数组，初始值为0。
2. ​**定义方向**​：顺时针方向顺序为右→下→左→上，用方向数组 `dirs = [[0,1],[1,0],[0,-1],[-1,0]]` 表示。
3. ​**边界控制**​：用 `top`（上边界）、`bottom`（下边界）、`left`（左边界）、`right`（右边界）限制当前层的填充范围。
4. ​**逐层填充**​：从外到内逐层填充，每层填充完一行/列后收缩边界，并切换方向。

```java
public int[][] generateSpiral(int m, int n) {
    int[][] matrix = new int[m][n];
    int num = 1;
    int top = 0, bottom = m - 1, left = 0, right = n - 1;
    int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}}; // 右→下→左→上
    int dir = 0; // 当前方向索引

    while (num <= m * n) {
        // 根据当前方向填充当前行/列
        switch (dir) {
            case 0: // 向右填充顶行
                for (int i = left; i <= right; i++) {
                    matrix[top][i] = num++;
                }
                top++; // 收缩上边界
                break;
            case 1: // 向下填充右列
                for (int i = top; i <= bottom; i++) {
                    matrix[i][right] = num++;
                }
                right--; // 收缩右边界
                break;
            case 2: // 向左填充底行
                for (int i = right; i >= left; i--) {
                    matrix[bottom][i] = num++;
                }
                bottom--; // 收缩下边界
                break;
            case 3: // 向上填充左列
                for (int i = bottom; i >= top; i--) {
                    matrix[i][left] = num++;
                }
                left++; // 收缩左边界
                break;
        }
        dir = (dir + 1) % 4; // 切换方向
    }
    return matrix;
}
```

#### **二、多层嵌套螺旋（方向交替）**
​**问题描述**​：生成一个螺旋数组，外层顺时针填充，内层逆时针填充，交替方向（如外层→顺时针，次外层→逆时针，依此类推）。  
​**核心差异**​：基础螺旋方向统一，升级后每层方向交替，需额外记录当前层的方向。
##### ​**算法思路**​
1. ​**分层处理**​：将螺旋视为多层同心环，每层独立填充。
2. ​**方向标记**​：用 `isClockwise` 标记当前层的方向（外层为 `true`，次外层为 `false`，依此类推）。
3. ​**填充逻辑**​：根据当前层的方向调整填充顺序（顺时针或逆时针）。
```java
public int[][] generateAlternatingSpiral(int n) {
    int[][] matrix = new int[n][n];
    int num = 1;
    int layer = 0; // 当前层数（从0开始）
    boolean isClockwise = true; // 外层默认顺时针

    while (layer <= n / 2) {
        int start = layer, end = n - 1 - layer;
        if (isClockwise) {
            // 顺时针填充当前层：右→下→左→上
            for (int i = start; i <= end; i++) matrix[start][i] = num++; // 右
            for (int i = start + 1; i <= end; i++) matrix[i][end] = num++; // 下
            for (int i = end - 1; i >= start; i--) matrix[end][i] = num++; // 左
            for (int i = end - 1; i > start; i--) matrix[i][start] = num++; // 上
        } else {
            // 逆时针填充当前层：下→右→上→左
            for (int i = start; i <= end; i++) matrix[i][start] = num++; // 下
            for (int i = start + 1; i <= end; i++) matrix[end][i] = num++; // 右
            for (int i = end - 1; i >= start; i--) matrix[i][end] = num++; // 上
            for (int i = end - 1; i > start; i--) matrix[start][i] = num++; // 左
        }
        layer++;
        isClockwise = !isClockwise; // 切换方向
    }
    return matrix;
}
```

#### **三、动态步长螺旋（步长递增）​**​
​**问题描述**​：生成一个螺旋数组，每一层的步长（每圈填充的元素数）递增（如第1层步长4，第2层步长8，第3层步长12，依此类推）。  
​**核心差异**​：基础螺旋每层步长固定（4*(n-1)），升级后步长随层数增加，需动态计算每层的填充长度。

##### ​**算法思路**​
1. ​**步长计算**​：第 `k` 层的步长为 `4 * (n - 1 - 2*(k-1))`（每层边长减少2，步长减少8）。
2. ​**边界调整**​：每填充完一层后，收缩边界并更新步长。
3. ​**循环填充**​：直到所有位置被填充或步长变为0（适用于非正方形）。

```java
public int[][] generateStepSpiral(int n) {
    int[][] matrix = new int[n][n];
    int num = 1;
    int top = 0, bottom = n - 1, left = 0, right = n - 1;
    int step = 4 * (n - 1); // 初始步长（最外层）

    while (step > 0) {
        // 右
        for (int i = left; i <= right; i++) matrix[top][i] = num++;
        top++;
        // 下
        for (int i = top; i <= bottom; i++) matrix[i][right] = num++;
        right--;
        // 左（若仍有空间）
        if (top <= bottom) {
            for (int i = right; i >= left; i--) matrix[bottom][i] = num++;
            bottom--;
        }
        // 上（若仍有空间）
        if (left <= right) {
            for (int i = bottom; i >= top; i--) matrix[i][left] = num++;
            left++;
        }
        step -= 8; // 步长递减8（每层4边，每边减少2个元素）
    }
    return matrix;
}
```

#### **四、螺旋数组的变形（带空洞）​**​
​**问题描述**​：生成一个螺旋数组，但每隔一定步数跳过一个位置（如每填充2个元素后跳过1个位置）。  
​**核心差异**​：基础螺旋连续填充，升级后需根据规则跳过部分位置，需额外记录填充计数。

##### ​**算法思路**​
1. ​**填充计数**​：用 `count` 记录当前已填充的元素数，当 `count % 3 == 0` 时跳过下一个位置（示例规则）。
2. ​**条件判断**​：在填充过程中，若遇到需要跳过的位置，则跳过并继续下一个位置。
```java
public int[][] generateHollowSpiral(int n) {
    int[][] matrix = new int[n][n];
    int num = 1;
    int top = 0, bottom = n - 1, left = 0, right = n - 1;
    int count = 0;

    while (num <= n * n) {
        // 右
        for (int i = left; i <= right; i++) {
            if (count % 3 != 0) { // 每3步跳过1个（示例规则）
                matrix[top][i] = num++;
            } else {
                matrix[top][i] = 0; // 空洞标记为0
            }
            count++;
        }
        top++;
        // 下
        for (int i = top; i <= bottom; i++) {
            if (count % 3 != 0) {
                matrix[i][right] = num++;
            } else {
                matrix[i][right] = 0;
            }
            count++;
        }
        right--;
        // 左（若仍有空间）
        if (top <= bottom) {
            for (int i = right; i >= left; i--) {
                if (count % 3 != 0) {
                    matrix[bottom][i] = num++;
                } else {
                    matrix[bottom][i] = 0;
                }
                count++;
            }
            bottom--;
        }
        // 上（若仍有空间）
        if (left <= right) {
            for (int i = bottom; i >= top; i--) {
                if (count % 3 != 0) {
                    matrix[i][left] = num++;
                } else {
                    matrix[i][left] = 0;
                }
                count++;
            }
            left++;
        }
    }
    return matrix;
}
```
