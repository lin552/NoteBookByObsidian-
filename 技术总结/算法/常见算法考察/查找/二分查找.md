#### 一、算法前提

二分查找仅适用于**有序数组**​（升序或降序，此处以升序为例）。若数组无序，需先排序（但排序的时间复杂度可能高于二分查找本身，需根据场景权衡）。

#### 二、核心思路
1. 初始化左右指针：左指针 `left` 指向数组起始位置（`0`），右指针 `right` 指向数组末尾（`nums.length - 1`）。
2. 循环缩小搜索范围：在 `left <= right` 条件下，计算中间位置 `mid`，比较中间值与目标值的大小：
    - 若中间值等于目标值，直接返回 `mid`（找到）。
    - 若中间值小于目标值，说明目标值在右半部分，调整左指针 `left = mid + 1`。
    - 若中间值大于目标值，说明目标值在左半部分，调整右指针 `right = mid - 1`。
3. 循环结束未找到目标值，返回 `-1`（或其他标识）。

#### 三、迭代实现（推荐）
迭代版本空间复杂度为 O(1)，无栈溢出风险，实际应用中更常用。
```java
/**  
 * 二分查找法实现  
 */  
public class BinarySearch {  
  
    public static void main(String[] args) {  
        int[] nums = {1, 3, 5, 7, 9, 11, 13};  
        int target = 7;  
        System.out.println(binarySearch(nums, target)); // 输出：3（索引为3）  
  
        target = 4;  
        System.out.println(binarySearch(nums, target));  
    }  
  
    public static int binarySearch(int[] nums, int target) {  
        //边界条件：数组为空或长度为0，直接返回-1  
        if (nums == null || nums.length == 0) {  
            return -1;  
        }  
  
        int left = 0; //左指针  
        int right = nums.length - 1; //右指针  
  
        while(left <= right) {  
            int mid = (left + right) / 2;  
            if (nums[mid] == target) {  
                return mid;  
            } else if (nums[mid] < target) {  
                left = mid + 1;  
            } else {  
                right = mid - 1;  
            }  
        }  
        return -1;  
    }  
}
```

#### 四、关键细节与注意事项
##### 1. 避免整数溢出（重要！）
计算中间位置 `mid` 时，若直接使用 `(left + right) / 2`，当 `left` 和 `right` 较大时（如接近 `Integer.MAX_VALUE`），可能导致整数溢出。  
​**正确写法**​：`mid = left + (right - left) / 2`（等价于 `(left + right) / 2`，但避免了溢出）。

##### 2. 循环条件：`left <= right`
若循环条件为 `left < right`，会导致当 `left` 和 `right` 相邻时漏查中间元素。例如，数组 `[2, 3]` 查找 `3` 时，`left=0, right=1`，若条件为 `left < right`，循环不会执行，直接返回 `-1`。  
​**正确条件**​：`left <= right`（确保最后一个可能的元素被检查）。

##### 3. 指针调整：`mid ± 1`
找到中间值后，需将指针调整为 `mid + 1` 或 `mid - 1`（而非 `mid`），否则可能陷入死循环。  
​**示例**​：数组 `[1, 2, 3, 4, 5]` 查找 `3`，若 `mid=2` 时调整 `left=mid`，则 `left` 和 `right` 始终为 `2`，循环无法退出。

##### 4. 处理重复元素
若数组包含重复元素，二分查找返回的索引是其中一个匹配项的位置（不一定是第一个或最后一个）。若需找边界（如第一个/最后一个出现的目标），需调整指针逻辑。
